# LearnLog — Tech Intelligence Knowledge Base

A Git-native knowledge base for AI, DevOps, Cloud, Kubernetes, AgentOps, observability, security, tools, experiments, architectures, and technical research.

## Philosophy
**Discover → Research → Verify → Experiment → Capture → Publish → Reuse**

## Repository map
- `research/` — validated research notes and trend analysis
- `tools/` — tool radar and tool evaluations
- `concepts/` — durable technical concepts
- `architectures/` — system designs and data-flow diagrams
- `labs/` — hands-on experiments and reproducible labs
- `trends/` — dated technology/trend tracking
- `content/` — publish-ready content source material
- `sources/` — source indexes and references
- `templates/` — standard formats for future entries
- `scripts/` — future automation for indexing/validation

## Content standard
Every important entry should distinguish:
1. What is documented by primary sources
2. What was observed hands-on
3. What is interpretation or takeaway
4. What remains uncertain

The repository is designed to become a future machine-readable knowledge source for RAG, semantic search, and AI agents.

## Notion
The human-facing research hub lives in the Notion **Tech Intelligence HUB**. Notion tracks metadata, relationships, workflow and publishing; GitHub stores durable technical artifacts, Markdown, code and reproducible experiments.
